# 📊 FNP Sales Analysis Dashboard – Excel

An interactive Sales Analysis Dashboard created using Microsoft Excel
to analyze sales performance, revenue trends, product performance,
occasions, order timing, and delivery insights.

## 📌 Dashboard Preview

![FNP Sales Analysis Dashboard](dashboard-preview.png)

## 📊 Project Overview

This project analyzes an e-commerce gifting dataset containing 1,000
orders and transforms the raw data into an interactive Excel dashboard.

The dashboard provides insights into:

- Total Orders
- Total Revenue
- Average Order Value
- Average Delivery Time
- Revenue by Occasion
- Revenue by Category
- Revenue by Month
- Revenue by Order Hour
- Top 5 Products by Revenue
- Top 10 Cities by Orders

## 📈 Key KPIs

| KPI | Value |
|---|---:|
| Total Orders | 1,000 |
| Total Revenue | ₹35,20,984 |
| Average Order Value | ₹3,520.98 |
| Average Delivery Time | 5.53 Days |

## 🔍 Key Insights

- Colors is the highest-revenue category.
- Anniversary is the highest-revenue occasion.
- February and August are the strongest revenue-generating months.
- Evening hours show strong revenue performance.
- Orders are distributed across a large number of cities.
- Interactive slicers allow users to filter the dashboard.
